# Textos bíblicos (JSON)

Os arquivos `*.json` desta pasta **não entram no git** (copyright das traduções).

Para desenvolver localmente, coloque aqui os dumps no formato esperado pelo app
(ex.: `nvi.json`, `ara.json`) — o `bible.cjs` os carrega automaticamente.

Não commite traduções sem verificar a licença de cada uma.
